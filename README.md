# Quantitative Equity Analysis of Indian IT Sector Stocks

## Project Overview

This project focuses on quantitative analysis of major Indian IT sector equities using historical market data.

The analysis was performed on:
- Infosys
- TCS
- Wipro

The project explores:
- correlation analysis,
- volatility behavior,
- trend-following indicators,
- and a simple moving average crossover trading strategy.

---

## Objectives

The main objectives of this project were:
- Analyze statistical relationships between IT equities
- Study volatility and market behavior
- Generate a simple quantitative trading idea
- Backtest the strategy using historical data
- Evaluate performance using risk-adjusted metrics

---

## Tools & Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Key Analysis Performed

### 1. Correlation Analysis
A correlation matrix of daily returns was used to study relationships between the selected equities.

### 2. Volatility Analysis
Rolling volatility was analyzed using standard deviation of returns.

### 3. Trend Analysis
20-day and 50-day moving averages were used to identify market trends.

### 4. Trading Strategy
A moving average crossover strategy was tested using historical market data.

### 5. Backtesting
Strategy performance was compared against a buy-and-hold benchmark.

---

## Key Insights

- Indian IT equities showed strong positive correlation.
- Volatility increased significantly during uncertain market periods.
- Trend-following indicators were useful in identifying medium-term momentum.
- The moving average strategy captured several major market trends.
